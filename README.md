# pixelito

A 16x16 pixel art editor for the browser. Pick a color, draw on the grid, and download your art as a PNG.

Made with plain HTML, CSS and JavaScript. No libraries, no build step.

## How to use it

1. Pick a color from the palette.
2. Click or drag on the grid to paint.
3. Use **Eraser** to fix mistakes and **Clear** to start over.
4. Hit **Download** to save your drawing as `pixelito.png`.

## AI use

I used Gemini AI while making this project, for three things:

- **Checking my code** to see if something was wrong or could be written better.
- **Fixing errors** when the page or the JavaScript didn't work.
- **Learning JavaScript**: I asked it to explain how things like events, the grid and the PNG download work, so I could understand the code instead of just copying it.
